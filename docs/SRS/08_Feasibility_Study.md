# Feasibility Study

## Introduction

A feasibility study evaluates whether a proposed project can be successfully developed using the available resources, time, technology, and budget. It helps determine if the project is practical and achievable within the given constraints.

For CyberHive AI, the feasibility study focuses on technical, economic, operational, schedule, and legal aspects of the project.

---

# 1. Technical Feasibility

CyberHive AI will be developed using technologies that are open source, well documented, and widely used in cybersecurity and software development.

### Technologies Used

- Kali Linux
- Cowrie Honeypot
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- Git and GitHub

All these technologies are compatible with each other and can be installed on a standard personal computer without requiring specialized hardware.

The development team already has experience with Python, Git, VirtualBox, and Kali Linux, making the implementation practical within the project timeline.

### Conclusion

The project is **technically feasible**.

---

# 2. Economic Feasibility

---

# 3. Operational Feasibility

CyberHive AI is intended for educational institutions, cybersecurity laboratories, and small organizations that want to monitor attack activity using a honeypot.

The system is designed with a simple web interface that allows administrators to:

- Monitor attacks
- View attacker behavior
- Analyze attack sessions
- Review alerts
- Generate reports

No advanced cybersecurity knowledge is required to navigate the dashboard.

### Conclusion

The project is **operationally feasible**.

---

# 4. Schedule Feasibility

The project follows the college Software Group Project (SGP) schedule.

### Planned Timeline

| Phase | Duration |
|--------|----------|
| Planning and Requirement Analysis | July |
| System Design | July – August |
| Backend Development | August |
| Frontend Development | August – September |
| Integration and Testing | September |
| Documentation and Final Submission | September – October |

The selected technologies are lightweight and suitable for development within one semester.

### Conclusion

The project is **feasible within the available time**.

---

# 5. Legal and Ethical Feasibility

CyberHive AI is developed strictly for educational and research purposes.

The project does **not** perform unauthorized attacks on external systems.

All testing will be conducted in a controlled environment using:

- Cowrie Honeypot
- Kali Linux
- Virtual machines
- Authorized penetration testing tools

External threat intelligence services will only be used according to their public API usage policies.

No personal or confidential user information will be collected.

### Conclusion

The project follows ethical cybersecurity practices and complies with the intended educational use.

---

# Overall Feasibility

Based on the technical, economic, operational, schedule, and legal analysis, CyberHive AI is a practical and achievable project.

The project makes use of freely available technologies, requires no additional hardware investment, and can be completed within the academic timeline. Its modular design also allows future enhancements without requiring major architectural changes.

Overall, CyberHive AI is considered a feasible project for successful implementation as a final-year Software Group Project.
