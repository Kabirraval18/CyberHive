# Functional Requirements

## Introduction

Functional requirements describe the features and services that CyberHive AI must provide to users. These requirements define the core functionality of the system and serve as the foundation for the development and testing phases.

---

# FR-01: User Authentication

### Description

The system shall provide a secure login page for administrators.

### Inputs

- Username
- Password

### Outputs

- Successful login
- Invalid login message for incorrect credentials

---

# FR-02: Honeypot Log Collection

### Description

The system shall collect attack logs generated by the Cowrie Honeypot.

### Inputs

- Cowrie JSON log files

### Outputs

- Parsed attack records ready for analysis

---

# FR-03: Log Processing

### Description

The system shall extract useful information from raw honeypot logs.

### Extracted Information

- Timestamp
- Session ID
- Source IP Address
- Username
- Password
- Event Type
- Commands Executed
- Login Status

---

# FR-04: Attack Database Management

### Description

The system shall store all processed attack information in a SQLite database.

### Functions

- Insert attack records
- Retrieve attack records
- Search attack records
- Filter attack records

---

# FR-05: Behavioral Analysis

### Description

The system shall analyze attacker sessions to identify similar attack behavior.

### Analysis Parameters

- Failed login attempts
- Number of commands executed
- Session duration
- Login frequency
- Command patterns

### Output

- Behavioral cluster ID
- Behavior label (Bot / Human / Suspicious)

---

# FR-06: Threat Intelligence Enrichment

### Description

The system shall retrieve additional information about attacker IP addresses using external threat intelligence services.

### Retrieved Information

- Abuse score
- Number of abuse reports
- Country
- ISP
- Usage type

---

# FR-07: MITRE ATT&CK Mapping

### Description

The system shall map attacker commands to relevant MITRE ATT&CK techniques.

### Example

| Command | Technique |
|----------|-----------|
| uname -a | System Information Discovery |
| cat /etc/passwd | File Discovery |
| wget | Ingress Tool Transfer |

---

# FR-08: Risk Score Calculation

### Description

The system shall calculate a risk score for every attack session.

### Risk Factors

- Failed login attempts
- Behavioral analysis
- Threat intelligence score
- Executed commands
- Predefined security rules

### Output

- Risk Score (0–100)
- Risk Level
  - Low
  - Medium
  - High
  - Critical

---

# FR-09: Security Recommendations

### Description

The system shall generate security recommendations based on the calculated risk score.

### Example Recommendations

- Block attacker IP
- Disable root login
- Enable multi-factor authentication
- Review SSH configuration
- Monitor repeated login attempts

---

# FR-10: Dashboard

### Description

The system shall provide an interactive web dashboard.

### Dashboard Features

- Total attacks
- Active attacker sessions
- High-risk attacks
- Attack timeline
- Country statistics
- Behavioral clusters
- MITRE ATT&CK mappings
- Threat intelligence information
- Alerts

---

# FR-11: Search and Filtering

### Description

The system shall allow users to search and filter attack data.

### Filters

- Date
- IP Address
- Risk Level
- Country
- MITRE Technique
- Session ID

---

# FR-12: Report Generation

### Description

The system shall generate downloadable PDF reports.

### Report Contents

- Attack summary
- Top attacker IPs
- Risk analysis
- MITRE ATT&CK techniques
- Threat intelligence summary
- Security recommendations

---

# FR-13: Validation Module

### Description

The system shall validate its detection logic using predefined attack scenarios.

### Validation Scenarios

- SSH brute-force attack
- Successful login
- Reconnaissance commands
- File download attempts

### Output

- Expected result
- Actual result
- Pass/Fail status

---

# FR-14: Logging

### Description

The system shall maintain internal logs for debugging and monitoring purposes.

### Logged Events

- User login
- Parser execution
- Database updates
- Threat intelligence API requests
- Report generation
