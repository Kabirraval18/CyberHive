# System Overview

## Introduction

CyberHive AI is a behavioral threat intelligence and security monitoring platform that uses a Cowrie Honeypot to capture and analyze cyberattacks. The platform is designed to collect real attack data, process security logs, identify attacker behavior, enrich attacks with external threat intelligence, calculate risk scores, map attacker actions to the MITRE ATT&CK framework, and present all the information through an interactive web dashboard.

The project combines cybersecurity concepts with data analysis and web technologies to create a practical monitoring platform that is suitable for educational institutions, research environments, and small organizations.

---

# Major System Modules

## 1. Honeypot Module

The Cowrie Honeypot acts as a fake SSH and Telnet server that records attacker activities without exposing a real system.

Its responsibilities include:

- Capturing login attempts
- Recording attacker commands
- Generating structured JSON logs
- Creating unique attack sessions

---

## 2. Log Processing Module

This module reads the JSON logs generated by Cowrie and extracts useful information.

The extracted information includes:

- Timestamp
- Session ID
- Source IP
- Username
- Password
- Login result
- Executed commands

The processed information is then stored in the SQLite database.

---

## 3. Database Module

SQLite is used to store processed attack information and analysis results.

The database maintains:

- Attack logs
- Session features
- Threat intelligence information
- Risk scores
- MITRE ATT&CK mappings
- Alerts
- Reports

---

## 4. Threat Intelligence Engine

This is the core intelligence component of the project.

It is responsible for:

- Detecting suspicious activity
- Calculating risk scores
- Enriching attacker IPs using external threat intelligence
- Mapping attacker behavior to MITRE ATT&CK techniques
- Generating security recommendations

---

## 5. Behavioral Intelligence Module

Instead of analyzing every attack separately, this module studies attacker behavior across complete sessions.

It considers factors such as:

- Failed login attempts
- Command execution patterns
- Session duration
- Login frequency
- Download activity

Similar sessions are grouped together using a lightweight machine learning algorithm to identify recurring attack campaigns.

---

## 6. Dashboard Module

The Flask-based dashboard provides an easy-to-understand view of all collected information.

The dashboard displays:

- Live attacks
- Attack statistics
- Risk scores
- Behavioral analysis
- Threat intelligence
- MITRE ATT&CK mapping
- Reports
- Alerts

---

## 7. Validation Module

The platform includes a validation framework to verify that the implemented detection logic works correctly.

Controlled attack scenarios such as SSH brute-force attacks and reconnaissance activities are performed against the honeypot.

The expected results are compared with the actual system output to evaluate the effectiveness of the platform.
