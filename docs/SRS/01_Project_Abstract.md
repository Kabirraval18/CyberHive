# Project Abstract

## CyberHive AI: Behavioral Threat Intelligence & Attack Analytics Platform Using Honeypot Security Logs

### Abstract

With the increasing number of cyberattacks on internet-facing systems, organizations need better ways to monitor and understand malicious activities. Traditional security monitoring tools and honeypots are useful for collecting attack data, but they often provide only basic information such as login attempts or attacker IP addresses. They usually lack deeper analysis that helps security administrators understand attacker behavior and take appropriate action.

CyberHive AI is a behavioral threat intelligence and security monitoring platform developed using the Cowrie SSH/Telnet Honeypot. The main objective of the project is to capture real attack attempts, analyze the collected security logs, identify suspicious behavior, and present meaningful insights through an easy-to-use web dashboard.

The system collects attack logs generated by the honeypot and processes them using Python. Important information such as attacker IP addresses, login attempts, executed commands, timestamps, and session details is extracted and stored in a SQLite database. Instead of only displaying these logs, CyberHive AI performs additional analysis to provide a better understanding of each attack.

One of the key features of the project is the behavioral intelligence module. It analyzes attacker sessions based on factors such as failed login attempts, command execution patterns, session duration, and login frequency. Similar attack sessions are grouped together using a lightweight machine learning technique, making it easier to identify automated attacks and recurring attack campaigns.

To provide more context about attackers, the platform also integrates with external threat intelligence services such as AbuseIPDB. This allows the system to check whether an attacker IP address has previously been reported for malicious activity and include that information in the analysis.

Another important feature is the MITRE ATT&CK mapping module. Instead of assigning attack techniques only based on the type of attack, the system observes the commands executed after login and maps them to relevant MITRE ATT&CK techniques. This provides a better understanding of the attacker's actions during a session.

CyberHive AI also calculates a risk score for every attack by considering multiple factors such as attack behavior, external threat intelligence, and predefined security rules. Based on the calculated risk level, the system generates security recommendations that can help administrators respond more effectively.

To evaluate the performance of the platform, different attack scenarios such as SSH brute-force attacks, reconnaissance activities, and command execution are performed against the honeypot. The generated results are compared with the expected outcomes to verify that the detection and risk scoring mechanisms are working correctly.

Finally, all the collected information is displayed through a Flask-based dashboard that provides live attack monitoring, behavioral analysis, MITRE ATT&CK mapping, threat intelligence details, alerts, reports, and overall security insights.

CyberHive AI demonstrates how behavioral analysis, threat intelligence, and security monitoring can be combined into a single platform to help security administrators better understand cyberattacks and improve incident response.
